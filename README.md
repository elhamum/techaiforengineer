# Tech AI for Engineers — Energy Consumption Prediction (Workshop)

This is a **community engagement workshop** for engineering students on how to use **AI (GitHub Copilot)** with **GitHub Codespaces** to build a simple machine-learning project for a final-year project.

You do **not** need to memorize code.  
You need to know **what you want to do** — Copilot helps write the code.

---

## What you will build
A complete mini data-science pipeline using a CSV file:

1. Upload a CSV (`house_consumption.csv`)
2. Load & explore data (`head`, `info`, `describe`)
3. Clean data (missing values, duplicates)
4. Visualize (correlation heatmap + scatter plot)
5. Train a regression model (Linear Regression)
6. Evaluate (R², MSE + Actual vs Predicted plot)

---

## Prerequisites
- A GitHub account
- GitHub Copilot access (recommended via GitHub Student Pack)
- No local installation required (we will use Codespaces)

---

## Step 1 — Fork this repository
1. Open this repository page on GitHub
2. Click **Fork** (top right)
3. Fork it to your account

You now have your own copy to work on.

---

## Step 2 — Open in GitHub Codespaces
1. In your forked repo, click the green **Code** button
2. Open the **Codespaces** tab
3. Click **Create codespace on main**

A browser-based VS Code editor will open.

---
